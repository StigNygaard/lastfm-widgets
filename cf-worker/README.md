# cf-worker proxy-API for lastfm-widgets

This is a Cloudflare Worker (Node.js) implemented "proxy-api" made by [burnblazter](https://github.com/burnblazter) for the [lastfm-widgets](https://github.com/StigNygaard/lastfm-widgets) project.

For information on how to set up and use this and other proxy-API solutions for lastfm-widgets, see [/services/README.md](https://github.com/StigNygaard/lastfm-widgets/blob/main/services/README.md).
